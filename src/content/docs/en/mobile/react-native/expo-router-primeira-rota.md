## What it is

**Expo Router** is Expo's **file-based** navigation system: every file inside `src/app/` becomes a screen, and `_layout.tsx` files define the navigator (Stack, Tabs…). It's the same model as the Next.js App Router, but for mobile.

## When to use

- In **any Expo app with more than one screen**. It's the recommended way to navigate.
- When you want deep links and typed routes without configuring anything by hand.
- When the app will also run on the web: each route becomes a URL.

## Step by step (starting from the `App.tsx` template)

### 1. Install the dependencies

```bash
npx expo install expo-router react-native-safe-area-context react-native-screens expo-linking expo-constants expo-status-bar
```

To also run on the web:

```bash
npx expo install react-dom react-native-web
```

### 2. Change the entry point

In `package.json`, `main` now points to Expo Router:

```json title="package.json" del={2} ins={3}
{
  "main": "index.ts",
  "main": "expo-router/entry"
}
```

After that, **delete `App.tsx` and `index.ts`**. The `src/app/` folder now decides what gets rendered.

### 3. Configure `app.json`

```json title="app.json"
{
  "expo": {
    "scheme": "readerfortabnews",
    "plugins": ["expo-router", "expo-status-bar"],
    "experiments": {
      "typedRoutes": true
    }
  }
}
```

- `scheme`: the deep link prefix (`readerfortabnews://...`).
- `typedRoutes`: generates types so `<Link href="...">` flags an error for a route that doesn't exist.

### 4. `@/` alias in TypeScript (optional, recommended)

```json title="tsconfig.json"
{
  "extends": "expo/tsconfig.base",
  "compilerOptions": {
    "strict": true,
    "paths": {
      "@/*": ["./src/*"]
    }
  },
  "include": ["**/*.ts", "**/*.tsx", ".expo/types/**/*.ts", "expo-env.d.ts"]
}
```

`.expo/types` in `include` is where the types generated by `typedRoutes` live.

### 5. Create the root layout

```tsx title="src/app/_layout.tsx"
import { Stack } from 'expo-router';
import { StatusBar } from 'expo-status-bar';

export default function RootLayout() {
  return (
    <>
      <Stack />
      <StatusBar style="auto" />
    </>
  );
}
```

`_layout.tsx` wraps every route in the folder. `<Stack />` stacks screens with the native header.

### 6. Create the first route

```tsx title="src/app/index.tsx"
import { StyleSheet, Text, View } from 'react-native';

export default function Index() {
  return (
    <View style={styles.container}>
      <Text>Open up src/app/index.tsx to start working on your app!</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#fff',
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```

`index.tsx` is the `/` route, the app's first screen.

### 7. Run it

```bash
npx expo start
```

## Final structure

```
src/
└── app/
    ├── _layout.tsx   → navigator (Stack)
    └── index.tsx     → route "/"
```

## Common pitfalls

- **Forgetting to change `main`**: the app keeps opening the old `App.tsx`, or breaks if it was deleted.
- **Putting components and hooks inside `src/app/`**: every file there becomes a route. Use `src/components/`, `src/hooks/` etc.
- **Installing with `npm install`**: use `npx expo install` to get SDK-compatible versions.
